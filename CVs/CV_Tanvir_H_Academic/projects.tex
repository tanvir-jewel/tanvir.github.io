\begin{rSection}{Selected Research Projects}
\begin{itemize}

    \item \textbf{Trojan-Assisted Meta-Attacks Against Design-for-Security Primitives:} Developed a unified framework to evaluate how hardware Trojans can systematically identify and neutralize Design-for-Security~(DfS) primitives in zero-trust microelectronics supply chains. Demonstrated attacks on Ring Oscillator Physically Unclonable Functions~(RO-PUFs) and Dynamically Obfuscated Scan Chains~(DOSC), enabling authentication bypass, scan-protection removal, and motivating Trojan-aware countermeasures.
    \item \textbf{Runtime Protection of Secrets in Untrusted COTS Processors:} Developed HOACS, a software-based framework that uses Residue Number Coding~(RNC) to keep sensitive data encoded during execution on commercial off-the-shelf~(COTS) processors. Implemented both C-library and LLVM-based transformations to protect cryptographic and arithmetic workloads from hardware-Trojan leakage and side-channel attacks without requiring hardware modification.
    \item \textbf{Side-Channel-Driven Security Evaluation of Opaque COTS Hardware:} Proposed a gray-box evaluation framework for assessing unknown COTS devices before deployment when internal design information is unavailable. The approach leverages power and electromagnetic~(EM) side-channel measurements to identify anomalous behaviors, guide vulnerability discovery, and support pre-deployment assurance under zero-trust hardware assumptions.
    \item \textbf{Gamified Learning Framework for Computer Hardware Fundamentals: } Developed hardware-based games to teach fundamental concepts of computer hardware using Verilog, FPGA, and ESP32 development boards.\textit{ Funded by NSF, 2022 to present.}
\end{itemize}
\end{rSection}
